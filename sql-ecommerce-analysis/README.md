# 📊 E-commerce Sales & Customer Analysis (SQL)

## 🔍 Overview
This project analyzes e-commerce order data to uncover revenue trends, customer behavior, and business insights.

## 🛠 Tools Used
- SQL (MySQL / PostgreSQL)

## 📂 Dataset
- 500+ order records
- Fields: order_id, customer_id, order_date, amount

## 📈 Key Analysis Performed
- Total Revenue Calculation
- Revenue by Year
- Monthly Sales Trends
- Top 5 Customers by Spending
- Repeat Customer Identification
- Average Order Value

## 💡 Key Insights
- Identified top revenue-generating customers
- Observed monthly sales growth trends
- Found repeat purchase patterns
- Calculated average order value for business decisions

## 🚀 Outcome
This project demonstrates strong SQL skills in data extraction, aggregation, and business-focused analysis.
